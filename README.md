Client for clickcrystals made by amusraubii2 (Amy or puppy)

Modules here will not include automatic turning whatsoever since CCS as of now flags this on GrimAC.
input use and input attack will not be used unless it does not flag.

Please download the Multi Key Bindings mod for modules requiring RMB hold, this will be mainly for Vanilla modules.
When you do, however, bind RMB to P, and bind LMB to O.

# How to use:

1. Download from release
2. Open up clickcrystals folder
3. Delete scripts folder (and back your current scripts up if you need to)
4. Copy and paste scripts folder back into clickcrystals
